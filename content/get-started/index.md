## Choose a starting point

- **You have never read Cyrillic.** Start at [Level 0](/level-0/). It is six
  units and it is the whole point of this course's shape: everything after it
  assumes you can decode.
- **You read Russian Cyrillic already.** Still start at Level 0, but treat it as
  a contrast course rather than an alphabet course. Units 1 and 5 exist
  precisely for you: `і/и`, `е/є`, `г/ґ`, and an apostrophe that does a
  different job from the Russian hard sign.
- **You can read Ukrainian aloud and type it.** Start at [A1](/level-a1/).
- **You are teaching.** Every unit is sized for a double lesson and ships with
  a slide deck, a worksheet, an answer key and teacher notes. The level pages
  give the full unit sequence so a term can be planned before the term starts.

## How a unit page is built

Every unit — at every level — follows the same five moves, in the same order,
under the same headings:

1. **Activate** — a short task that surfaces what you already know or can
   guess. No new material.
2. **Input** — the model: a dialogue, a reading text, a vocabulary set, a
   grammar point. Original or openly licensed, always attributed.
3. **Practise** — controlled exercises with an answer key in a collapsible
   block, so you can check without being shown too early.
4. **Apply** — the open task: write, speak, role-play, mediate. This is the
   part that is graded in the exam.
5. **Reflect** — a self-check against the unit's can-do statements.

Below that sit the unit's downloads and, where audio exists, a player with the
transcript beside it. Each unit has a **sibling exam page** in the same format
as the level exam, so exam practice is not a separate activity bolted on at the
end.

## Reading the glosses

In Level 0 and early A1 every Ukrainian word appears three ways: in Cyrillic,
in Latin transliteration, and with its stress marked — `Украї́на · Ukraina`.
The transliteration is scaffolding with a scheduled removal date; it thins out
through A1 and is gone at A2. Do not learn from it: use it to check yourself
after you have tried the Cyrillic.

## Typing Ukrainian

You cannot do the written tasks in this course with a German, English or
French keyboard, and you should not try to work around it by pasting letters.
Install a Ukrainian layout; it takes a few minutes once.

**Windows.** Settings → Time & language → Language & region → *Add a language*
→ **Українська (Ukrainian)** → add the keyboard. Switch layouts with
`Win`+`Space`.

**macOS.** System Settings → Keyboard → Text Input → *Edit…* → `+` →
**Ukrainian**. Both *Ukrainian* and *Ukrainian — PC* are offered; choose
*Ukrainian — PC* if you want the same key positions as on a Ukrainian
Windows machine. Switch with `Ctrl`+`Space`.

**Linux (GNOME/KDE).** Settings → Keyboard → Input Sources → `+` →
**Ukrainian**. The variants `Ukrainian (legacy)` and `Ukrainian (typewriter)`
differ mainly in the placement of `ґ` and the apostrophe; the default variant
is the safe choice. Switch with `Super`+`Space`.

**Android / iOS.** Add *Ukrainian* under keyboard languages. On both systems
`ґ` and the apostrophe are reached by long-pressing `г` and the quote key
respectively.

{{< callout type="warning" title="The three keys that catch people out" >}}
On the standard Ukrainian layout: **`і`** sits where Latin `s` is, **`ї`**
where `]` is, and **`є`** where `'` is. The letter **`ґ`** is not on the base
layout at all on most systems — it is `AltGr`+`г` (Windows/Linux) or
`Option`+`г` (macOS). The **apostrophe** `'` used inside words such as
`м'ясо` is the key left of `1`, not the Latin quote mark: writing `м"ясо` or
`м'ясо` with a typographic quote is wrong, and spell-checkers will not
forgive it.
{{< /callout >}}

If you cannot install a layout — on a school machine, say — a phonetic online
keyboard will get you through an exercise, but plan to fix it: the Level 0 exam
asks you to type, not to paste.

## Downloads

Each unit links two artefacts, both committed to the repository rather than
generated on demand:

- an **editable slide deck** (`.odp`, with a PDF alongside) for teaching;
- a **printable worksheet** (PDF) for classwork or homework.

Exams are published as separate PDFs under the level's download folder, with
answer key and grading scale.

Everything is CC BY-SA 4.0: use it, print it, adapt it, keep the attribution
and share adaptations under the same licence.

## Fonts, if something looks wrong

If `ґ`, `ї` or `є` appear as boxes or in a visibly different typeface from the
surrounding text, your device is falling back to a font without full Ukrainian
Cyrillic coverage. It is a display problem, not a content problem — but it is
worth reporting as an issue on the repository, with your operating system and
browser, because the fix belongs on this end.
